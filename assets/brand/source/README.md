# Payr Brand Assets

The project owner confirmed the v2 design and the right to distribute this
artwork in the public repository on 2026-09-07. The supplied source is
`logo-v2.png`; its original creator/generation tool is not recorded here.
This confirmation does not assign a new third-party or public-domain license.

`payr-mark-v2.png` is derived from `assets/brand/source/logo-v2.png`.
The original remains unchanged. The display asset uses a 768px square crop
at x=231, y=231, resized to 256px, preserving transparency.

Website and email headers and the social preview use this mark. The app's
PNG app icon uses the same crop scaled to 176px and centered in a 256px light
background with a 48px corner radius. The Apple touch output is 180px square;
the ICO fallback contains a 32px image. These role-specific exports keep the
navy mark visible in dark browser chrome. The original four references in
`assets/brand/` remain unchanged.

## Historical Concepts

`mascot-sheet.png` and `payr-brand-banner.png` are preserved source concepts,
not current product promises. The banner's "Instant liquidity" is not an
available capability or payment guarantee. Reminder, analytics, and security
imagery in the mascot sheet does not establish shipped features or guarantees.
These originals are not substituted for the production brand exports.
